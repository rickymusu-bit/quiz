# quiz

Materiali del quiz di Riccardo Musumarra, separati dal repository `rickymusu-bit/fisica` su richiesta dell’autore.

- `Chi_vuol_essere_rimandato_quiz_v3_20261008.html`: gioco a quiz.
- `Chi_vuol_essere_rimandato_regole_v9_20261008.html`: regolamento.
- `Template_dataset_quiz_argomenti_v1_20261008.json`: modello del dataset.
- `Prompt_generazione_dataset_quiz_v1_20261008.txt`: istruzioni per preparare i dataset.

Scarica gli HTML e aprili nel browser. I file sono stati trasferiti integralmente, senza modificarne il contenuto. La provenienza e gli hash sono registrati in `PROVENIENZA.json`; la cronologia precedente rimane nel repository di origine. Nessuna pubblicazione GitHub Pages è stata attivata per il quiz.
